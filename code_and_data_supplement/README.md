# CPO-Guard: Code and Data Supplement

This repository contains the implementation of **CPO-Guard**, a collaborative
fast--slow framework for E-commerce Livestream Compliance Anomaly Detection
(ELCAD), as described in the accompanying paper.

## Environment

| Item | Value |
|------|-------|
| Python | 3.10 |
| PyTorch | >= 2.1.0 |
| CUDA | 12.1 |
| GPU | NVIDIA A100 80GB |
| FP16 inference | Yes |
| Batch size for latency | 1 |

Install dependencies:

```bash
pip install -r requirements.txt
```

## Data Organization

### Sample Schema

Each sample is one 60-second livestream clip. See [data/data_schema.json](data/data_schema.json) for the complete schema.

Key fields per sample:

```
{
  "sample_id": "clip_0001",
  "session_id": "session_01",
  "asr_text": "...",
  "visual_caption": "...",
  "comment_text": "...",
  "propagation_seq": [[n,d,q,δ_P,ρ_P,I_P], ...],   # 12 windows × 6
  "outcome_seq":      [[s,Δs,δ_O,ρ_O], ...],       # 12 windows × 4
  "label": 0,
  "rationale": "..."
}
```

The provided data files contain **anonymized** sample identifiers, session
identifiers, ASR transcripts, comments, and sales records. No original user,
host, shop, or platform identifiers are included.

### Split Metadata

- `data/split_metadata/train.jsonl` — 394 clips (83 risky), 26 sessions
- `data/split_metadata/val.jsonl` — 93 clips (22 risky), 6 sessions
- `data/split_metadata/test.jsonl` — 500 clips (135 risky), 47 sessions

Splits are session-disjoint and host-disjoint (Section 4.3).

### Sample Data

`data/sample_data/` contains a small anonymized subset for verifying the pipeline.

### Raw Videos

Raw livestream videos are **not redistributed** due to copyright, portrait-right,
and platform-policy considerations. Visual-semantic captions (generated by
Qwen3.5-9B) are provided as precomputed fields.

## Reproducing Results

### Quick Start

```bash
# Reproduce the reported results from the released processed inputs
bash scripts/reproduce_main_results.sh
```

### Step-by-Step

**1. Construct CPO windows (Section 5.2):**

```bash
python preprocessing/construct_windows.py --config configs/data.yaml
```

Parameters used: W=12 windows, window_size=5s, λ_I=0.8, α_P=20, b_P=20, α_O=8, b_O=10, ε=0.1.

**2. Build retrieval case base (Section 5.3):**

```bash
python retrieval/build_case_base.py \
    --train_samples data/split_metadata/train.jsonl \
    --output data/case_base.jsonl
```

Retrieval uses all-MiniLM-L6-v2 embeddings, K=3, with same-session exclusion.

**3. Run CMR inference (Section 5.3):**

For Qwen2.5-14B-Instruct (local FP16, single NVIDIA A100 80GB):

```bash
python cmr/inference.py \
    --config configs/cmr_qwen25_14b.yaml \
    --input data/split_metadata/test.jsonl \
    --output outputs/cmr_14b_results.jsonl \
    --case_base data/case_base.jsonl
```

For Qwen3.5-9B (SGLang API):

```bash
# Start SGLang server first (see below)
python cmr/inference.py \
    --config configs/cmr_qwen35_9b.yaml \
    --input data/split_metadata/test.jsonl \
    --output outputs/cmr_9b_results.jsonl \
    --case_base data/case_base.jsonl
```

**4. Train LRE (Section 5.4):**

```bash
python lre/train.py --config configs/lre.yaml
```

LRE uses BERT-base-Chinese (frozen first 10 layers, fine-tuned last 2),
BiGRU (hidden=32, bidirectional), evidence-aware gate, and 4096-dim
reasoning-semantic projection. Loss: L = L_score + 0.3 · L_align.

**5. Run collaborative inference (Section 5.5):**

```bash
python routing/collaborative_inference.py \
    --lre_scores outputs/lre_scores.jsonl \
    --cmr_scores outputs/cmr_14b_results.jsonl \
    --labels data/split_metadata/test.jsonl \
    --theta 0.30 --tau 0.75 \
    --sweep
```

**6. Reproduce tables (Section 6):**

```bash
python evaluation/reproduce_tables.py --result_dir outputs/
```

### Output Correspondence

| Output | Script |
|--------|--------|
| Table 1: Main results | `evaluation/reproduce_tables.py` |
| Table 2: Ablation results | Run with modality/component variants |
| Supplementary: threshold sensitivity | `routing/collaborative_inference.py --sweep` |

## Randomness and Reproducibility

- Random seed: 42, 123, 456 (training); 42 (inference)
- CMR temperature: 0.1
- CMR top-p: default
- CMR max output tokens: 1024
- Prompt version: `cmr/prompts/cpo_prompt.py` (CPO_PROMPT_TEMPLATE)
- Model checkpoints: Qwen2.5-14B-Instruct (HuggingFace), Qwen3.5-9B (SGLang)

## SGLang Server Setup (Qwen3.5-9B)

```bash
python -m sglang.launch_server \
    --model-path Qwen/Qwen3.5-9B \
    --port 8000 \
    --tp-size 1 \
    --mem-fraction-static 0.8 \
    --context-length 26214
```

## Model Checkpoints

- **Qwen2.5-14B-Instruct**: Publicly available at `Qwen/Qwen2.5-14B-Instruct` on HuggingFace.
- **Qwen3.5-9B**: Publicly available at `Qwen/Qwen3.5-9B` on HuggingFace.
- **BERT-base-Chinese**: Publicly available at `bert-base-chinese` on HuggingFace.
- **all-MiniLM-L6-v2**: Publicly available at `sentence-transformers/all-MiniLM-L6-v2` on HuggingFace.
- **Chinese-RoBERTa**: Publicly available at `hfl/chinese-roberta-wwm-ext` on HuggingFace.
- **LRE checkpoint**: Trained by `lre/train.py`. Not included due to size; reproducible via the training script.

## CPO-Guard Template Classifier (I_P)

The coordinated interaction indicator uses Chinese-RoBERTa fine-tuned with
20 positive templates (coordinated promotional interaction patterns) and
20 negative templates (ordinary audience comments). Template lists are
provided in `data/coordinated_interaction_templates.json`.
